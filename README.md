# Plume Libre (prototype)

Prototype de plateforme d'écriture et de lecture anonyme, imaginé par Roxane.

- Tout le site tient dans `index.html` (HTML/CSS/JS, données de démo, sauvegarde dans le navigateur).
- Version mobile : barre d'onglets en bas, installable sur l'écran d'accueil (`manifest.webmanifest`, `sw.js`, icônes).
- Déploiement : site statique Render (https://roxane-plume-libre.onrender.com), mis à jour à chaque push sur `main`.
